# Streaq

### Streaks worth keeping.

**Streaq** is a habit tracker built around streaks and the friends who keep them with
you. Track your habits, share them with the people who keep you honest, and watch the
days stack up.

🌐 **[streaq.club](https://streaq.club)** — Streaq is out and open to everyone.
[Open the app](https://app.streaq.club) and start your first streak.

---

This repository holds the source for the Streaq landing page — a small, fast static
site built with [Astro](https://astro.build).
